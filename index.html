Panduan Mengolah Data Sakernas dengan Python

Dari data SPSS (.sav) menjadi tabel Excel berisi TPT, TPAK, status pekerjaan, lapangan usaha, dan upah, dengan penimbang. Tidak perlu bisa pemrograman: cukup ikuti langkahnya satu per satu.

Skrip olah_sakernas.py membaca file .sav langsung, menghitung semuanya, lalu menulis dua file: tabel Excel dan file SPSS baru (usia 15 tahun ke atas, dilengkapi variabel baru). File .sav asli tidak diubah.

1. Yang akan Anda dapatkan

File hasilIsi
Hasil_Sakernas.xlsxLima sheet: TPT_TPAK, Status_Pekerjaan, Lapangan_Usaha, Upah, Cek_Upah.
Data Awal 51_usia15plus.savData SPSS baru: hanya usia 15+, ditambah variabel JenisKegiatan, AK3, AKBAK, status_pekerjaan, kategori172025, upah_gaji, laba_usaha.

Setiap sheet dirinci menurut: total, jenis kelamin, kota/desa, kabupaten/kota, dan kabupaten/kota menurut kota/desa. Semua angka memakai penimbang.

2. Yang perlu disiapkan

  • Komputer Windows dengan koneksi internet (hanya untuk memasang Python dan pustaka).
  • File data Sakernas format SPSS, misalnya Data Awal_51.sav.
  • File skrip olah_sakernas.py (unduh dari halaman GitHub ini).

Skrip mengenali nama variabel standar Sakernas, yaitu penimbang weightr, kabupaten kdkab dan nmkab, jenis kelamin dem_sex, serta kota/desa klas. Kalau data Anda memakai nama lain, lihat bagian pengaturan variabel.

3. Memasang Python

Python adalah program yang menjalankan skrip. Cukup dipasang sekali.

  1. Buka python.org/downloads lalu klik tombol kuning Download Python.
  2. Buka file yang terunduh (python-3.xx.x-amd64.exe).
  3. Di layar pertama, centang kotak Add python.exe to PATH di bagian bawah, lalu klik Install Now.
  4. Tunggu sampai muncul Setup was successful, lalu klik Close.

Kotak Add python.exe to PATH sangat penting. Kalau lupa dicentang, perintah python dan pip nanti tidak dikenali. Solusinya: jalankan installer lagi, pilih Modify, lalu aktifkan opsi PATH.

Cek apakah berhasil

  1. Tekan tombol Windows, ketik cmd, lalu tekan Enter. Jendela hitam (Command Prompt) akan terbuka.
  2. Ketik perintah berikut, lalu Enter:
python --version

Kalau muncul tulisan seperti Python 3.13.1, Python sudah siap. Kalau muncul pesan 'python' is not recognized, tutup jendela, buka lagi, dan coba ulang. Bila masih sama, lihat catatan di atas tentang PATH.

4. Memasang pustaka tambahan

Skrip memerlukan empat pustaka (paket tambahan): pandas untuk mengolah tabel, pyreadstat untuk membaca/menulis file SPSS, xlsxwriter untuk menulis Excel, dan numpy untuk hitungan angka. Di Command Prompt, jalankan:

pip install pandas pyreadstat xlsxwriter

Tunggu sampai selesai (bisa beberapa menit). Selesai bila baris terakhir berbunyi Successfully installed .... Langkah ini cukup sekali per komputer.

Kalau muncul 'pip' is not recognized, pakai: python -m pip install pandas pyreadstat xlsxwriter

5. Menyiapkan folder kerja

Paling mudah: taruh semuanya dalam satu folder, misalnya D:\REKON II AGT 2026.

D:\REKON II AGT 2026\
   Data Awal_51.sav        (data Anda)
   olah_sakernas.py        (skrip ini)

Hasil akan muncul di folder yang sama. Folder tidak perlu dibuat khusus.

Jalankan ulang akan menimpa file hasil dengan nama yang sama. Salin dulu hasil yang ingin Anda simpan, dan tutup file Excel/SPSS hasil sebelum menjalankan ulang.

6. Mengisi pengaturan skrip

  1. Klik kanan olah_sakernas.py, pilih Open with lalu Notepad.
  2. Cari bagian PENGATURAN di dekat bagian atas.
  3. Ubah tiga baris ini sesuai lokasi dan nama file Anda:
SAV_PATH = r"D:\REKON II AGT 2026\Data Awal_51.sav"
OUT_XLSX = r"D:\REKON II AGT 2026\Hasil_Sakernas.xlsx"
OUT_SAV  = r"D:\REKON II AGT 2026\Data Awal 51_usia15plus.sav"
  1. Simpan dengan Ctrl + S, lalu tutup Notepad.

Jangan hapus huruf r di depan tanda kutip dan jangan hapus tanda kutipnya. Hanya ubah teks di dalamnya. Tips: untuk menyalin lokasi file, tahan Shift, klik kanan file, pilih Copy as path.

Pengaturan lain (opsional)

PengaturanFungsi
MODE_UPAH = "karyawan"Upah dihitung hanya untuk buruh/karyawan/pegawai (standar). Ganti "semua" untuk menghitung pendapatan (upah + laba) semua pekerja.
UMUR_MIN = 15Batas umur penduduk usia kerja untuk TPAK.

Kalau nama variabel di data Anda berbeda

Bila skrip melapor ada variabel yang tidak ketemu, buka daftar_variabel.txt (dibuat otomatis di folder kerja), cari nama kolom yang benar, lalu isi di KOL. Contoh:

KOL = {"weight": "weightr", "kab": "kdkab", "sex": "dem_sex", "klas": "klas"}

7. Menjalankan skrip

Cara A (klik dua kali): klik dua kali olah_sakernas.py. Jendela hitam akan terbuka, menampilkan proses, dan berhenti dengan tulisan Tekan Enter untuk menutup jendela ini.... Baca dulu pesannya, lalu tekan Enter.

Cara B (lewat Command Prompt):

  1. Buka folder kerja di File Explorer.
  2. Klik kotak alamat di bagian atas, ketik cmd, lalu Enter.
  3. Ketik perintah ini, lalu Enter:
python olah_sakernas.py

Pesan yang menandakan berhasil:

Weight=weightr  Kab=kdkab  JK=dem_sex  Kota/Desa=klas
File SPSS baru (...) -> ...
Selesai -> D:\REKON II AGT 2026\Hasil_Sakernas.xlsx

Pastikan baris pertama menunjukkan variabel yang benar. Proses butuh beberapa detik sampai beberapa menit, tergantung ukuran data.

8. Membaca hasilnya

SheetIsi
TPT_TPAKPenduduk 15+, bekerja, pengangguran, angkatan kerja, bukan angkatan kerja, TPAK (%), TPT (%), dan jumlah sampel.
Status_PekerjaanPenduduk bekerja menurut 7 status pekerjaan: jumlah jiwa dan persen.
Lapangan_UsahaPenduduk bekerja menurut 17 kategori KBLI 2025: jumlah jiwa dan persen.
UpahRata-rata dan median upah per kelompok dan per lapangan usaha, dalam rupiah.
Cek_UpahPemeriksaan: berapa persen tiap status pekerjaan yang memiliki isian upah dan laba.

Persentase ditampilkan dua digit desimal. Rincian kota/desa per kabupaten ada di blok paling bawah tiap tabel.

Pemeriksaan penting: bandingkan TPT dan TPAK total dengan hasil SPSS Anda. Kalau sama, logikanya cocok. Perhatikan juga kolom Sampel (n): kelompok dengan sampel sedikit menghasilkan angka yang kurang stabil.

9. Kalau muncul pesan gagal

Skrip sengaja memberi pesan berbahasa Indonesia yang menunjuk penyebabnya. Penyebab umum:

Pustaka belum terpasang

Pesan: Pustaka berikut belum terpasang di komputer ini... Jalankan perintah yang tertera di pesan itu (biasanya pip install ...), lalu coba lagi.

Tutup file hasil dulu / akses file ditolak

File Excel atau SPSS hasil masih terbuka. Tutup file itu, lalu jalankan lagi.

Folder tujuan atau file data tidak ditemukan

Periksa penulisan SAV_PATH, OUT_XLSX, dan OUT_SAV: huruf drive, nama folder, dan nama file harus persis sama, termasuk spasi dan garis bawah (Data Awal_51.sav berbeda dengan Data Awal 51.sav).

Variabel tidak ketemu otomatis

Skrip menampilkan kolom yang mirip beserta labelnya dan menyimpan daftar lengkap ke daftar_variabel.txt. Isi nama yang benar di KOL (lihat bagian ini).

Kesalahan tak terduga

Akan muncul tulisan Terjadi kesalahan tak terduga disertai pesan panjang berwarna putih. Salin seluruh pesannya dan laporkan lewat tab Issues di GitHub, sertakan juga versi Windows dan Python Anda.

Jendela hitam tertutup sendiri

Gunakan cara B di langkah menjalankan skrip, supaya jendela tidak menutup dan pesannya terbaca.

10. Catatan cara hitung

  • Definisi bekerja, pengangguran, status pekerjaan, dan lapangan usaha mengikuti syntax SPSS Sakernas (jenis kegiatan seminggu terakhir; KBLI 2025 17 kategori).
  • TPAK = angkatan kerja ÷ penduduk usia 15+ × 100. TPT = pengangguran ÷ angkatan kerja × 100.
  • Penimbang: semua jumlah adalah penjumlahan bobot, bukan hitungan responden mentah.
  • Upah: hanya buruh/karyawan/pegawai (status pekerjaan 4) dengan upah lebih dari 0, yaitu upah uang + barang. Pengusaha dan pekerja mandiri memperoleh laba, bukan upah, sehingga tidak dicampur. Sheet Cek_Upah membantu memeriksa isian di data Anda.
  • Rata-rata upah dihitung terbobot; median upah juga terbobot.
Skrip ini alat bantu pengolahan. Selalu bandingkan angka total dengan hasil SPSS atau publikasi resmi sebelum dipakai.
