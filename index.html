Panduan Mengolah Data Sakernas dengan Python

Persiapan sekali saja: pasang Python, pasang pustaka, unduh dua skrip. Setelah itu dua langkah rutin: imputasi (memasukkan hasil konfirmasi lapangan ke data) lalu olah (menghasilkan tabel Excel).

1. Pasang Python

  1. Buka python.org/downloads, klik Download Python, lalu buka file yang terunduh.
  2. Centang Add python.exe to PATH di bagian bawah layar pertama, lalu klik Install Now.
  3. Selesai bila muncul Setup was successful.

Kotak Add python.exe to PATH wajib dicentang. Kalau terlewat, jalankan installer lagi, pilih Modify, lalu aktifkan opsi PATH.

2. Pasang pustaka

Tekan tombol Windows, ketik cmd, tekan Enter. Di jendela hitam yang terbuka, jalankan:

pip install pandas pyreadstat xlsxwriter openpyxl

Tunggu sampai muncul Successfully installed. Kalau muncul 'pip' is not recognized, pakai python -m pip install pandas pyreadstat xlsxwriter openpyxl.

3. Unduh skrip

Unduh imputasi_sakernas.py Unduh olah_sakernas.py

Simpan keduanya di folder kerja yang sama dengan file data .sav (file data dikirim oleh pengelola). Susunan foldernya:

D:\FOLDER KERJA\
   Data Awal_51.sav          (data awal)
   imputasi_sakernas.py
   olah_sakernas.py
   Konfirmasi\               (folder: taruh Excel konfirmasi di sini)

Kalau tombol tidak mengunduh: klik kanan tautan ini atau tautan ini, pilih Save link as, dan pastikan nama file berakhiran .py, bukan .txt.

4. Imputasi: masukkan hasil konfirmasi lapangan

Skrip ini membaca Data Awal_51.sav (tidak diubah) dan semua file Excel di folder Konfirmasi. Responden yang dikonfirmasi Bekerja diisi data pekerjaannya (status, KBLI, KBJI, jam kerja, penghasilan), lalu disimpan sebagai data baru. Excel konfirmasi baru kapan saja boleh ditambahkan ke folder itu.

a. Atur lokasi file. Buka imputasi_sakernas.py dengan Notepad (klik kanan, Open with, Notepad). Di bagian PENGATURAN, ubah empat baris ini, lalu simpan (Ctrl + S):

SAV_AWAL          = r"D:\FOLDER KERJA\Data Awal_51.sav"
FOLDER_KONFIRMASI = r"D:\FOLDER KERJA\Konfirmasi"
OUT_SAV           = r"D:\FOLDER KERJA\Data Awal_51_imputasi.sav"
OUT_LOG           = r"D:\FOLDER KERJA\Log_Imputasi.xlsx"

Jangan hapus huruf r dan tanda kutipnya. Tip: tahan Shift, klik kanan file, pilih Copy as path.

b. Jalankan. Klik dua kali imputasi_sakernas.py. Berhasil bila muncul ringkasan dan tulisan Selesai.

c. Periksa Log_Imputasi.xlsx.

SheetGunanya
RingkasanJumlah yang diterapkan, dilewati, dan belum lengkap.
PerubahanSetiap perubahan: nilai lama dan nilai baru per responden.
Tidak_lengkapDikonfirmasi bekerja tetapi KBLI, status, atau jam kerja kosong. Perlu dikejar ke lapangan.
Status_tdk_sesuaiStatus di Excel berbeda dengan hasil hitung (misalnya pekerja bebas pertanian tetapi KBLI non-pertanian).
Kode_statusKode status yang dipakai, dipelajari dari responden yang sudah bekerja di data. Pastikan masuk akal.
Tidak_ketemu, Tidak_cocokBaris Excel yang tidak ada di data, atau identitasnya tidak cocok (dilewati).

Data baru juga memuat variabel flag_imputasi (1 = baris diubah berdasarkan konfirmasi).

5. Olah: hasilkan tabel Excel

Skrip ini membaca data hasil imputasi, menghitung semua angka dengan penimbang, lalu menulis dua file hasil.

a. Atur lokasi file. Buka olah_sakernas.py dengan Notepad. Di bagian PENGATURAN, ubah tiga baris ini sesuai folder Anda, lalu simpan:

SAV_PATH = r"D:\FOLDER KERJA\Data Awal_51_imputasi.sav"
OUT_XLSX = r"D:\FOLDER KERJA\Hasil_Sakernas.xlsx"
OUT_SAV  = r"D:\FOLDER KERJA\Data Awal 51_usia15plus.sav"

b. Jalankan. Klik dua kali olah_sakernas.py. Jendela hitam berhenti dengan tulisan Tekan Enter untuk menutup jendela ini. Berhasil bila ada baris Selesai -> ...Hasil_Sakernas.xlsx.

c. Buka hasilnya.

FileIsi
Hasil_Sakernas.xlsxSheet TPT_TPAK, Perbandingan_2025_2026, Status_Pekerjaan, Lapangan_Usaha, Upah, Cek_Upah. Dirinci menurut total, jenis kelamin, kota/desa, kabupaten/kota, dan kabupaten/kota menurut kota/desa.
Data Awal 51_usia15plus.savData SPSS baru, hanya usia 15+, dengan variabel tambahan JenisKegiatan_imputasi, AK3, AKBAK, status_pekerjaan, kategori172025, upah_gaji, laba_usaha.

Urutan rutinnya selalu imputasi dulu, baru olah. Setiap ada Excel konfirmasi baru, jalankan keduanya lagi. File hasil ditimpa setiap kali dijalankan: tutup file Excel/SPSS hasil sebelum menjalankan ulang, dan salin dulu hasil yang ingin disimpan.
