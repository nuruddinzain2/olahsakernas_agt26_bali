Panduan Mengolah Data Sakernas dengan Python

Tiga langkah persiapan sekali saja: pasang Python, pasang pustaka, unduh skrip. Setelah itu, data SPSS Anda menjadi tabel Excel dengan satu kali jalan.

1. Pasang Python

  1. Buka python.org/downloads, klik Download Python, lalu buka file yang terunduh.
  2. Centang Add python.exe to PATH di bagian bawah layar pertama, lalu klik Install Now.
  3. Selesai bila muncul Setup was successful.

Kotak Add python.exe to PATH wajib dicentang. Kalau terlewat, jalankan installer lagi, pilih Modify, lalu aktifkan opsi PATH.

2. Pasang pustaka

Tekan tombol Windows, ketik cmd, tekan Enter. Di jendela hitam yang terbuka, jalankan:

pip install pandas pyreadstat xlsxwriter

Tunggu sampai muncul Successfully installed. Kalau muncul 'pip' is not recognized, pakai python -m pip install pandas pyreadstat xlsxwriter.

3. Unduh skrip

Unduh olah_sakernas.py

Simpan di folder kerja yang sama dengan file data .sav (file data dikirim oleh pengelola).

Kalau tombol tidak mengunduh: klik kanan tautan ini, pilih Save link as, dan pastikan nama file berakhiran .py, bukan .txt.

4. Cara kerja

Skrip membaca file .sav langsung, menghitung semua angka dengan penimbang, lalu menulis dua file hasil di folder yang sama. File .sav asli tidak berubah.

a. Atur lokasi file. Buka olah_sakernas.py dengan Notepad (klik kanan, Open with, Notepad). Di bagian PENGATURAN, ubah tiga baris ini sesuai folder dan nama file Anda, lalu simpan (Ctrl + S):

SAV_PATH = r"D:\FOLDER KERJA\Data Awal_51.sav"
OUT_XLSX = r"D:\FOLDER KERJA\Hasil_Sakernas.xlsx"
OUT_SAV  = r"D:\FOLDER KERJA\Data Awal 51_usia15plus.sav"

Jangan hapus huruf r dan tanda kutipnya. Tips: tahan Shift, klik kanan file, pilih Copy as path.

b. Jalankan. Klik dua kali olah_sakernas.py. Jendela hitam menampilkan prosesnya dan berhenti dengan tulisan Tekan Enter untuk menutup jendela ini. Berhasil bila ada baris Selesai -> ...Hasil_Sakernas.xlsx.

c. Buka hasilnya.

FileIsi
Hasil_Sakernas.xlsxSheet TPT_TPAK, Status_Pekerjaan, Lapangan_Usaha, Upah, Cek_Upah. Dirinci menurut total, jenis kelamin, kota/desa, kabupaten/kota, dan kabupaten/kota menurut kota/desa.
Data Awal 51_usia15plus.savData SPSS baru, hanya usia 15+, dengan variabel tambahan JenisKegiatan_imputasi, AK3, AKBAK, status_pekerjaan, kategori172025, upah_gaji, laba_usaha.

Setiap kali dijalankan, kedua file hasil ditimpa. Tutup file Excel/SPSS hasil sebelum menjalankan ulang, dan salin dulu hasil yang ingin disimpan.

Kalau muncul tulisan [GAGAL], bacalah pesannya: skrip menyebut penyebab dan cara memperbaikinya. Bila belum jelas, kirim pesan itu ke pengelola.
